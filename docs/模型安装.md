# 模型安装

本页面讲清楚「装哪些模型、放哪、从哪下载、文件名必须叫什么」。
让一个 agent（或第一次用的人）照着就能把模型装好、`tools\serve.cmd` 一把拉起。

> **为什么要专门写**：模型文件不入版本控制（体积大），clone 下来后 `app\models\`
> 是空的，必须自己装。而且这些**不是标准的 SD checkpoint**，是 stable-diffusion.cpp
> 专用的 GGUF / safetensors，文件名必须和启动脚本里写死的一字不差，否则
> `serve.ps1` 找不到文件直接报错。

---

## 0. 一句话总结

| 需要几个模型 | 放到哪 | 加载方式 |
|---|---|---|
| 默认 **Z-Image Turbo**：3 个文件 | `app\models\zimage\` | `tools\serve.cmd`（默认） |
| 备用 **SD 1.5**：1 个文件 | `app\models\` | `tools\serve.cmd sd15` |

`app\models\` 结构装好长这样：

```
app\models\
├── sd15.safetensors                  # 备用：SD 1.5 单文件
└── zimage\
    ├── z_image_turbo-Q4_K.gguf       # 扩散主模型
    ├── ae.safetensors                # VAE
    └── qwen3-4b-Q4_K_M.gguf          # 文本编码器（LLM）
```

> 大小：Z-Image 三件套约 6.2 GB，SD 1.5 约 2 GB。

---

## 1. 文件名是硬要求（先读这条）

`tools\serve.ps1` 里**写死了**这些文件名，装的时候**必须**叫这个名字：

```powershell
Z-Image 默认分支（$D = app\models\zimage）：
  --diffusion-model  z_image_turbo-Q4_K.gguf
  --vae              ae.safetensors
  --llm              qwen3-4b-Q4_K_M.gguf

SD 1.5 分支：
  -m                 sd15.safetensors
```

**尤其注意**：从 HuggingFace 直接下载的 Qwen 文本编码器，官方默认文件名是
`Qwen3-4B-Instruct-2507-Q4_K_M.gguf`（带 `Instruct-2507` 后缀）。本工程要的是
`qwen3-4b-Q4_K_M.gguf`。下载后**必须重命名**，否则启动报「找不到模型」。

保存目录用 `app\models\`（相对工程根）。工程整体可搬移，模型路径由脚本自动推导。

---

## 2. 默认：Z-Image Turbo（推荐，质量最好）

需要 3 个文件，全部放 `app\models\zimage\`。

### ① 扩散主模型 `z_image_turbo-Q4_K.gguf`

官方量化仓库：<https://huggingface.co/leejet/Z-Image-Turbo-GGUF>

取 `Q4_K_4.gguf` 级别那个，下载后重命名为 `z_image_turbo-Q4_K.gguf`。

直链示例（`Q4_K`）：

```
https://huggingface.co/leejet/Z-Image-Turbo-GGUF/resolve/main/z_image_turbo-Q4_K.gguf
```

> 想小一点的用 `Q3_K` / 内存充足的用更大量化，文件名对应改（文档按 `Q4_K` 写，
> 别的量化请把 `serve.ps1` 里对应行也同步改掉）。

### ② VAE `ae.safetensors`

来自 [Comfy-Org/z_image_turbo](https://huggingface.co/Comfy-Org/z_image_turbo) 的拆分 VAE：

```
https://huggingface.co/Comfy-Org/z_image_turbo/resolve/main/split_files/vae/ae.safetensors
```

### ③ 文本编码器 `qwen3-4b-Q4_K_M.gguf`

来自 [unsloth/Qwen3-4B-Instruct-2507-GGUF](https://huggingface.co/unsloth/Qwen3-4B-Instruct-2507-GGUF)：

```
https://huggingface.co/unsloth/Qwen3-4B-Instruct-2507-GGUF/resolve/main/Qwen3-4B-Instruct-2507-Q4_K_M.gguf
```

**下载后改名为** `qwen3-4b-Q4_K_M.gguf`。

---

## 3. 备用：SD 1.5（快，512px）

1 个文件，放 `app\models\`（**不是** zimage 子目录）：

```
https://huggingface.co/stable-diffusion-v1-5/stable-diffusion-v1-5/resolve/main/v1-5-pruned-emaonly.safetensors
```

保存为 `sd15.safetensors`。想更紧凑可用 GGUF 版（文件名相应改成 `sd15.gguf`，
并改 `serve.ps1` 的 `-m` 行）。

启动用 `tools\serve.cmd sd15`。

---

## 4. 怎么下载（给 agent）

文件较大，推荐断点续传的下载方式：

**Windows PowerShell：**

```powershell
$dst = "app\models\zimage"
New-Item -ItemType Directory -Force -Path $dst | Out-Null

# 扩散模型（~3.6 GB）
curl.exe -L -C - -o "$dst\z_image_turbo-Q4_K.gguf" `
  "https://huggingface.co/leejet/Z-Image-Turbo-GGUF/resolve/main/z_image_turbo-Q4_K.gguf"

# VAE（~0.3 GB）
curl.exe -L -C - -o "$dst\ae.safetensors" `
  "https://huggingface.co/Comfy-Org/z_image_turbo/resolve/main/split_files/vae/ae.safetensors"

# 文本编码器（~2.3 GB）—— 注意改名的位置
curl.exe -L -C - -o "$dst\qwen3-4b-Q4_K_M.gguf" `
  "https://huggingface.co/unsloth/Qwen3-4B-Instruct-2507-GGUF/resolve/main/Qwen3-4B-Instruct-2507-Q4_K_M.gguf"
```

> `curl.exe`（Windows 自带）而不是 `curl`，`-C -` 是断点续传，中断重跑即可。

**核对**：

```powershell
Get-ChildItem app\models\zimage | Select-Object Name, @{n='GB';e={[math]::Round($_.Length/1GB,2)}}
# 期望：
#   ae.safetensors             ~0.31
#   qwen3-4b-Q4_K_M.gguf       ~2.33
#   z_image_turbo-Q4_K.gguf    ~3.60
```

## 5. 装好后验证

```powershell
# 期望三个名字、大小都对
Get-ChildItem app\models -Recurse -File | Select-Object FullName, @{n='GB';e={[math]::Round($_.Length/1GB,2)}}
```

然后启动：

```powershell
.\tools\serve.cmd          # Z-Image Turbo
# 或
.\tools\serve.cmd sd15     # SD 1.5
```

浏览器打开，出图即成功。

**常见启动报错排查**：

| 症状 | 原因 | 处理 |
|---|---|---|
| 启动即退出 / 日志报找不到模型文件 | 文件名和 §1 不一致 | 按 §1 重命名 |
| `zimage` 目录为空但不报错 | 装错位置 | 确认放 `app\models\zimage\` |
| 有图但很糊 / 发灰 | 用了 `Q3_K` 以下或有 VAE 缺失 | 装 `ae.safetensors` 到 zimage |
| 内存不足 | 未加 `--offload-to-cpu` | 用本项目 `serve.ps1`（自带该参数） |

---

## 6. 完全走 CPU（无独显/核显，内存够大）

`tools\serve.ps1` 默认已带 `--offload-to-cpu --diffusion-fa`，
Z-Image 三件套在 AMD 核显（Vulkan）+ CPU 上即可跑，约 30~60 秒/张
（512×768）。更慢的纯 CPU 环境建议改用 SD 1.5 分支（`serve.cmd sd15`）。

> 若你的显卡不支持 Vulkan，可把 `serve.ps1` 默认分支去掉 `--diffusion-fa`
> 但保留 `--offload-to-cpu`，退化为纯 CPU 推理（更慢但能跑）。
